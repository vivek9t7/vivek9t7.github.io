Software and data

Modelling tools I work with, code I maintain, and datasets I have compiled.

Model development and builds

  • SWAT+ source-code builds. Compilation of the SWAT+ source code (version 62.3) into executables for Windows and Linux using Intel Fortran compilers and the Ninja build system, including source-level modification for research use.
  • SWAT+ / gwflow coupling. Configuration and application of the coupled surface water–groundwater implementation for the Hindon River Basin.
  • Reproducible Python workflows. Scenario automation, model output extraction, and multi-criteria evaluation of management alternatives.

Data compiled

  • Long-term groundwater nitrate records for the Hindon River Basin, assembled from national monitoring archives, with censored-data handling and gap filling.
  • Stream water quality records for the basin, screened for reporting inconsistencies.
  • Land use and agricultural management data assembled for catchment model setup.

Data availability follows the terms of the source archives and of the HIROS project. Enquiries about derived datasets are welcome by email.
